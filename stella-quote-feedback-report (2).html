How These Events Are Generated

When a user finishes reviewing a Stella-generated quote, the frontend calls POST /servicetrade/feedback with a JSON body containing eventType (STELLA_QUOTE_CONTINUED or STELLA_QUOTE_ABANDONED), an optional jobId, and — for continued events only — the resulting quoteId. Account context (stella_account_id, stella_trace_id) is passed as query parameters.

The orchestrator Lambda validates the eventType, assembles a StellaQuoteFeedback object, and logs it via console.log, which routes to CloudWatch Logs. No external storage is written — these logs are the system of record. CloudWatch Logs are forwarded to QA1 (staging/dev) or Dunnwell (prod) via the log-forwarder Lambda subscribed to each function's log group.

Data in this report: CloudWatch Insights export from the production orchestrator log group, covering May 26 – June 2, 2026, filtered to STELLA_QUOTE_CONTINUED and STELLA_QUOTE_ABANDONED messages.
